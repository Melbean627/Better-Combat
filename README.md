# Offhand Sword Lunge

A Fabric mod for Minecraft 1.21.1. Pressing right-click with a sword in the
offhand adds a forward lunge and deals 10 durability damage to that sword.
Each right-click press triggers at most one lunge, with a 2-second cooldown.
Holding left-click with an axe for more than 0.5 seconds throws it forward;
the axe is consumed from the hand and can be retrieved by picking up the
thrown item.

Build with Java 21 using `gradlew.bat build` on Windows or `./gradlew build`
on macOS and Linux.
