# Offhand Sword Lunge

A Fabric mod for Minecraft 1.21.1. Right-clicking with a sword in the offhand
adds a forward lunge and deals 10 durability damage to that sword. The lunge
uses the player's facing direction and runs on the server.

Build with Java 21 using `gradlew.bat build` on Windows or `./gradlew build`
on macOS and Linux.
