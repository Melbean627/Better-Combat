# Offhand Sword Lunge

A Fabric mod for Minecraft 1.21.1. Pressing right-click with a sword in the
offhand adds a forward lunge and deals 10 durability damage to that sword.
Holding right-click does not repeat the lunge. Movement is predicted on the
client and validated and applied by the server.

Build with Java 21 using `gradlew.bat build` on Windows or `./gradlew build`
on macOS and Linux.
